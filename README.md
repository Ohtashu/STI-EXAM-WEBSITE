# STI-EXAM Website

The Special Examination Management System (SEMS) is a web-based application designed to streamline the process of requesting and managing special examinations for STI students.

## Features

- **Student Features**
  - Submit special examination requests
  - Upload supporting documents
  - Track request status
  - Receive notifications

- **Administrator Features**
  - Manage examination requests
  - Schedule examinations
  - Manage student records
  - System configuration
  - User management

## Technology Stack

- PHP
- MySQL
- Bootstrap 5
- JavaScript
- HTML5/CSS3

## Live Demo

Visit our live demo at: [https://ohtashu.github.io/STI-EXAM-WEBSITE/](https://ohtashu.github.io/STI-EXAM-WEBSITE/)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Ohtashu/STI-EXAM-WEBSITE.git
   ```

2. Set up your web server (Apache/Nginx) with PHP support

3. Import the database schema (if available)

4. Configure your database connection

5. Access the application through your web browser
